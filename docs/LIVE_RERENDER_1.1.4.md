# Перерендер клипов из прямого эфира (1.1.4)

## Проблема

В редакторе готового клипа из эфира при нажатии «Перерендерить» появлялось
«Исходное видео не найдено».

Причина: `pipeline.rerender_clip()` требовал `project["source"]` — скачанный исходный
файл. У live-проектов `source` не бывает: рекордер пишет HLS-сегменты в
`projects/<id>/segments/` (плюс `init.mp4` для fMP4), а `source` заполняется только у
обычных проектов после скачивания.

Заодно нашлась связанная ошибка: слова live-клипов сохранялись с таймингами
относительно начала окна анализа (0…N секунд), а не относительно эфира. Из-за этого
субтитры при перерендере съезжали к началу клипа.

## Что изменено

### 1. Перерендер из сегментов эфира

`rerender_clip()` теперь:

1. проверяет `project.source`; если его нет — ищет `segments/times.jsonl`;
2. вырезает нужный диапазон `[start, end]` из записанных сегментов через тот же
   локальный HLS-плейлист, что и нарезка эфира (`live._render_live_clip`);
3. рендерит клип с новыми настройками (шрифт, темп, цвет, кадрирование, хук);
4. обновляет файл `clips/clip_NN.mp4` на месте.

Поддержаны и MPEG-TS (Twitch/Kick обычно), и fMP4 (`init.mp4` + `#EXT-X-MAP`).

### 2. Понятные ошибки

`POST /api/clips/{id}/rerender` до запуска рендера отвечает 400, если:

- папки `segments/` больше нет — «Запись эфира не найдена — перерендер невозможен»;
- `end` выходит за `meta.live_duration` — «Конец клипа выходит за пределы записанной
  части эфира».

### 3. Абсолютные тайминги слов

- `process_windows()` теперь сохраняет слова со сдвигом `+win_start` — во времени эфира.
- Для старых live-клипов (слова от начала окна) при перерендере применяется
  нормализация `live._absolute_words()`: первый блок ставится к началу клипа.
- `_render_live_clip()` по-прежнему переводит абсолютные слова в клип-относительные.

### 4. Редактор

Ползунок «Конец» в редакторе live-клипа ограничен `meta.live_duration` (длиной
записанной части эфира), а не концом текущего клипа — можно удлинить фрагмент в
пределах записи.

## Проверка

- `tools/live_selftest.py` — новый тест: live-проект без `source`, 2 сегмента по 5 с,
  клип 1–6 с перерендеривается, статус `ready`, в ASS есть `\k`-караоке.
- Ручной тест на фикстурах: новый клип с абсолютными словами и «старый» клип со словами
  от начала окна — оба перерендерились, длительности 8 и 7 с, субтитры на месте.
- API: `end=25` при записанных 20 с → 400 с понятным текстом; `end=10` → 200 и клип
  готов.
- UI (Playwright): редактор live-клипа открывается, максимум конца = 19.8 с (запись
  20 с), смена темпа и «Перерендерить» → клип обновляется, ошибок в консоли нет.
