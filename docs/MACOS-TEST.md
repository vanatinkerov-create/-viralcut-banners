# ViralCut 1.5.8 — тестовая сборка для macOS

## Требования

- macOS 12 или новее, **Apple Silicon** (arm64). На Intel-маках этот архив не
  запустится — соберите сборку под свою архитектуру из исходников.
- Свободное место: ~1 ГБ (приложение 866 МБ, модель распознавания уже внутри).

## Установка

1. Откройте DMG и перетащите `ViralCut.app` в «Программы» (или распакуйте ZIP).
2. Первый запуск: **ПКМ по приложению → «Открыть» → «Открыть»**. Приложение
   подписано ad-hoc, но не нотаризовано, поэтому двойной клик macOS блокирует.
   Альтернатива в терминале:

   ```bash
   xattr -dr com.apple.quarantine /Applications/ViralCut.app
   ```

3. Данные и журнал: `~/Library/Application Support/ViralCut/app.log`.

## Что проверить

1. **Ролик 5–15 минут** с речью и паузами → «Сделать нарезки» → в параметрах
   включить **«Вырезать паузы»**. Субтитры не должны отставать/спешить, кроп —
   «прыгать» на склейках.
2. **«Пересобрать в умный кроп» / «Пересобрать в 1080p»** — окно не закрывается,
   клипы перерисовываются.
3. **Виджет нагрузки**: CPU/RAM/GPU (на Apple Silicon GPU читается через ioreg;
   в простое 0–5% — норма).
4. **Настройки → «Разобрать журнал»**: отчёт должен показать версию 1.5.8 и
   состояние системы.
5. Закройте окно и откройте «Разобрать журнал» снова: должен быть маркер
   `ViralCut stop` (штатное закрытие).

## Что прислать, если что-то не так

- `~/Library/Application Support/ViralCut/app.log` целиком (или текст из
  «Разобрать журнал»).
- На каком шаге упало/зависло, что было на экране.
- Версию macOS и модель Mac (Apple M1/M2/M3/M4).

## Известные ограничения тестовой сборки

- Подпись ad-hoc, без нотаризации: предупреждение Gatekeeper — ожидаемо.
- Модель Whisper внутри, интернет для распознавания не нужен; для загрузки
  видео по ссылке интернет, конечно, нужен.
- YouTube HD зависит от PO-token провайдера; при его сбое приложение честно
  уходит в SD.
