> ViralCut превращает длинные видео и стримы в готовые вертикальные клипы для Shorts, Reels и TikTok.
> Он сам находит сильные моменты, кадрирует по лицу. И накладывает субтитры.
> До пятидесяти клипов за один запуск — с вашим шрифтом и цветом.
> Прямой эфир режется прямо во время трансляции: клипы появляются, пока стрим ещё идёт.
> И всё это локально на вашем Mac: без облака, аккаунтов и подписок.
> ViralCut. Вирусные клипы за минуты.

в субтитрах и на экране — латиница **ViralCut**.

## Как сделано

- **Голос**: macOS `say` (Milena, ru-RU, 165 слов/мин), нормализация -16 LUFS.
- **Музыка**: Mixkit Free License, «Motivating Mornings» (Ahjay Stelino), коммерческое
  использование без указания авторства; громкость -20 дБ с ducking под голос.
- **Слайды**: 1920×1080, брендовый градиент, скриншоты приложения из `docs/screenshots/`.
- **Монтаж**: ffmpeg — лёгкий zoom/pan по слайдам, кроссфейды 0.4 с, финальные fade in/out,
  встроенные soft-субтитры (mov_text).

## Как заменить

1. Текст — в `script.md`; озвучка: `say -v Milena -r 165 -o voice.aiff "…"`.
2. Слайды — PNG 1920×1080; длительность сцены = длительность реплики + 0.3 с.
3. Сборка: ffmpeg с `xfade`/`zoompan`, музыка через `amix` + `sidechaincompress`,
   субтитры через `-c:s mov_text`.
4. Если нужен вертикальный вариант 1080×1920 — слайды пересобираются под 9:16,
   исходники скриншотов и текста уже есть.
