# ViralCut — промо 30 секунд (релиз на GitHub)

Ролик про то, что приложение уже доступно: финальный кадр ведёт на
**github.com/vanwild11/viralcut**, там же лежат релизы для macOS и Windows.

на экране и в субтитрах — латиница **ViralCut**.

## Как пересобрать

Нужен ffmpeg с libx264/libfreetype (в проекте используется бандл из
`viralcut-studio/dist/.../imageio_ffmpeg/binaries/ffmpeg-macos-aarch64-v9.0`)
и Python с Pillow.

```sh
python3 build_slides.py            # slides/s1..s6.png
python3 build_video.py             # out/*.mp4, *.srt, *-poster.jpg
python3 build_vertical.py          # slides-v/s1..s6.png
python3 build_video.py vertical    # out-v/*.mp4, *.srt, *-poster.jpg
```

Тайминги считаются от фактической длительности реплик: `LEAD`, `GAP`, `PRE_CUT`,
`XFADE`, `TAIL` в начале `build_video.py`. Чтобы поменять ссылку — правится
`slide_release()` в `build_slides.py` и `SUBS` в `build_video.py`.


## Вертикальная версия (TikTok)

`build_vertical.py` собирает отдельную композицию, а не режет широкую:

- 1080×1920, 30 fps; хук вверху, «плавающее» окно приложения в середине,
  под речью — вшитая подпись (TikTok смотрят без звука).
- Фон под окном — размытая копия того же скриншота с тёмным скримом, поэтому
  вертикаль не выглядит пустой, а текст всегда читается.
- Безопасные зоны TikTok: контент держится в x 64…950 (правая колонка кнопок
  свободна), подписи заканчиваются выше y 1650, бренд по центру сверху.
- Громкость −14.2 LUFS (норма соцсетей), без fade-in с чёрного, финальный
  кадр держится до конца.
- Ссылка на GitHub — крупной плашкой в кадре и текстом «Ссылка — в описании».

## Что проверено

- 905 кадров, 30.16 с, 1920×1080, 30 fps; видео декодируется без ошибок.
- Интегральная громкость −16.1 LUFS; голос слышен в каждой из шести сцен,
  музыка приглушается под речью (sidechain), в конце плавно уходит.
- Субтитры вшиты как отдельная дорожка `mov_text` (rus) и лежат рядом `.srt`.
- Слайды: полупрозрачные плашки и иконка замка композитятся корректно
  (Pillow не умеет рисовать alpha прямо в RGB — используется отдельный слой).
- Рендер кадров не проверялся «глазами»: у модели в этой сессии нет ввода
  изображений, поэтому вёрстка проверена измерениями (габариты текста,
  контраст, отсутствие выхода за поля), а не визуально.
