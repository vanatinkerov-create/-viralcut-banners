Нужен интернет?

Только чтобы скачать видео по ссылке. Нарезка, распознавание и рендер идут локально.

Куда уходят видео и звук?

Никуда. Всё лежит в папке приложения на вашем компьютере: `%APPDATA%\\ViralCut` на Windows или `~/Library/Application Support/ViralCut` на macOS.

Можно свои шрифты?

Да, TTF/OTF загружаются в редакторе и шаблоне. В комплекте 24 шрифта, включая рукописные и спортивные.

Windows-версия официальная?

Да, собирается из того же кода через GitHub Actions. macOS-архив подписан ad-hoc, поэтому первый запуск может потребовать «Открыть» через правый клик.
