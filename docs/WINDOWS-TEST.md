# ViralCut 1.5.8 — тестовая сборка для Windows (из исходников)

> **Есть две Windows-раздачи.** Если нужен вариант «скачал и запустил, ничего не
> устанавливая» — берите `ViralCut-1.5.8-windows-x64-portable.zip` (~690 МБ):
> внутри Python, зависимости, ffmpeg и модель, инструкция — в
> `README-WINDOWS-PORTABLE.txt`. Ниже — лёгкий вариант из исходников (57 МБ),
> он нужен для диагностики и для сборки exe на самой Windows.

Это **не .exe**, а переносимый набор исходников: собран на macOS, поэтому exe
здесь нет — Windows-бинарник собирается на самой Windows одной командой (см.
ниже) либо через GitHub Actions. Зато этот пакет позволяет проверить всё
главное уже сегодня: окно, мониторинг GPU, «Пересобрать», вырезание пауз и
журнал падений.

## Что нужно

- Windows 10/11 x64.
- Python 3.12 x64 (install_windows.bat поставит через winget).
- Microsoft Edge WebView2 Runtime (тоже ставится автоматически; на Windows 11
  обычно уже есть).
- Интернет при первом запуске: скачается модель распознавания речи (~460 МБ).

## Запуск

1. Распакуйте архив в папку без кириллицы в пути, например `C:\ViralCut-test`.
2. Запустите `install_windows.bat` (поставит Python 3.12 и WebView2, создаст
   `.venv-win`, установит зависимости — первый раз несколько минут).
   Если Python 3.12 уже есть — можно сразу `run_windows.bat`.
3. Откроется окно ViralCut. Данные и журнал: `%APPDATA%\ViralCut\app.log`.

## Быстрая проверка без окна (30 секунд)

```powershell
powershell -ExecutionPolicy Bypass -File tools\windows_smoke.ps1 -Source
```

Скрипт поднимет приложение без окна, дёрнет `/api/health`, три раза
`/api/system` (именно там читаются PDH-счётчики GPU и раньше мог падать
процесс), покажет `/api/diagnostics` и хвост `app.log`.

## Что проверить руками

1. **Загрузка файла** (лучше ролик 5–15 минут с речью и паузами) → «Сделать
   нарезки» → в параметрах включить **«Вырезать паузы»**.
2. **«Пересобрать в 1080p»** на готовом проекте — окно не должно закрываться.
   Это главный регресс, который проверяем.
3. **Виджет нагрузки**: CPU/RAM/GPU. В подсказке к имени GPU должно быть
   `источник: pdh` (Intel/AMD/NVIDIA), `nvidia-smi` (NVIDIA) или `adl` (AMD).
4. **Настройки → «Разобрать журнал»**: отчёт должен показать версию 1.5.8 и
   корректно описать состояние.
5. Закройте приложение обычным способом и снова откройте «Разобрать журнал»:
   в логе должен появиться маркер `ViralCut stop`.

## Что прислать, если что-то пошло не так

- `%APPDATA%\ViralCut\app.log` целиком (или вывод «Разобрать журнал»).
- На каком шаге упало/зависло и что было на экране.
- Строку `GPU:` из виджета и `источник:`.
- Версию Windows и модель видеокарты.

## Собрать настоящий .exe на Windows (по желанию)

```powershell
powershell -ExecutionPolicy Bypass -File build_windows.ps1
```

Скрипт поставит зависимости, скачает модель Whisper (с проверкой sha256 в CI),
соберёт `dist\ViralCut\ViralCut.exe` и упакует
`release\ViralCut-<версия>-windows-x64.zip` + `SHA256SUMS-windows.txt`.

## Известные ограничения тестовой сборки

- Приложение не подписано: SmartScreen покажет «Неизвестный издатель» →
  «Подробнее» → «Выполнить всё равно». Это ожидаемо для теста.
- Модель Whisper качается при первом запуске; на медленном канале это займёт
  время.
- PO-token провайдер (HD с YouTube) распаковывается при первом запуске в
  `%APPDATA%\ViralCut\runtime\vendor` — это нормально, папка ~200 МБ.
