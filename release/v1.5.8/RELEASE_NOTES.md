## ViralCut 1.5.8

**Паузы вырезаются до рендера, реакции аудитории и смены сцен влияют на выбор,
GPU виден на всех видеокартах, а падения на Windows оставляют след в журнале.**

### Главное

- **«Вырезать паузы».** Тишина и «эээ…» убираются склейкой до рендера: видео и
  звук режутся `trim`/`atrim` и склеиваются, слова и субтитры пересчитываются на
  новую шкалу времени, умный кроп едет за ними. Опция есть на главной и в
  редакторе клипа.
- **Частичное скачивание снова работает.** `yt-dlp` для `download_ranges`
  проверяет команду `ffmpeg` в PATH и не смотрит на `ffmpeg_location` — из-за
  этого на сборке с бинарником `ffmpeg-macos-aarch64-v9.0` падало «ffmpeg is
  not installed». Теперь канонические `ffmpeg`/`ffprobe` лежат в `data/bin`,
  ссылка проверяется запуском и пересоздаётся, всем вызовам yt-dlp выставляются
  PATH, `ffmpeg_location` и contextvar постпроцессоров.
- **Смех, аплодисменты и смены сцен.** Реакции считаются по звуку (numpy),
  смены сцен — по гистограммам ключевых кадров (OpenCV). Моменты с реакцией
  получают балл, границы клипов притягиваются к монтажной склейке. Без
  numpy/OpenCV поиск моментов работает как раньше.
- **GPU в `/api/system` для NVIDIA, Intel и AMD.** PDH-счётчики «GPU Engine»
  читаются с явными прототипами ctypes (без них 64-битный HANDLE обрезался —
  вероятная причина «нажал Пересобрать — приложение закрылось»), 3D-движки
  суммируются по адаптеру; запасные пути — `nvidia-smi` и ADL для AMD.
  В ответе есть `vendor` и `source` (`pdh` / `nvidia-smi` / `adl` / `none`).
- **Диагностика падений.** `faulthandler` пишет дамп в небуферизованный
  `app.log`, маркеры запуска/остановки, перехват исключений потоков, этапы
  `[stage] …`, самопроверка `[selfcheck] …` (ffmpeg, модель, GPU, WebView2).
  Разбор: `python -m viralcut.diagnostics`, `GET /api/diagnostics` и кнопка
  «Разобрать журнал» в настройках. Стек при закрытии сигналом не выдаётся за
  нативное падение.
- **Тестовая сборка Windows без exe.** ZIP ~690 МБ со встроенным Python,
  зависимостями, ffmpeg и моделью Whisper: распаковал и запустил, докачивать
  нечего. Классический `.exe` собирается на Windows (`build_windows.ps1`) или
  в CI.

### Установка

- **macOS 12+ (Apple Silicon):** `ViralCut-1.5.8.dmg`. Первый запуск — ПКМ →
  «Открыть» (подпись ad-hoc, без нотаризации).
- **Windows 10/11 x64:** `ViralCut-1.5.8-windows-x64-portable.zip` —
  распаковать и запустить `ViralCut.bat` (ничего не устанавливается). Нужен
  только WebView2 Runtime; на Windows 11 он уже есть.
