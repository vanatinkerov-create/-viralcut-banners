# ViralCut 1.3.0

Локальная нарезка длинных видео в вертикальные клипы для YouTube Shorts, TikTok и
Instagram Reels. Всё считается на вашем компьютере: видео, звук и текст никуда не
отправляются.

## Что нового в 1.3.0

### Приложение само сообщает о новой версии

Раз в 6 часов ViralCut одним запросом спрашивает у GitHub Releases номер
последнего релиза. Если он новее установленной версии, в сайдбаре — над карточкой
Telegram — появляется аккуратная плашка:

> **Доступна версия 1.3.1**
> Скачать с GitHub

Клик открывает страницу релиза в браузере, где лежит архив под вашу платформу.
Один тост на версию, «×» прячет плашку до следующего релиза.

Что важно знать:

- **Наружу уходит только версия приложения** в User-Agent. Ни видео, ни пути к
  файлам, ни настройки не отправляются — принцип «всё локально» сохранён.
- **Офлайн ничего не ломает:** проверка идёт в фоне с таймаутом 5 секунд,
  результат кешируется в `data/update.json`, при ошибке сети приложение молчит и
  повторит позже.
- **Черновики и пререлизы игнорируются**, чтобы не предлагать бету тем, кто её
  не просил.
- **Можно выключить:** переменной `VIRALCUT_UPDATE_CHECK=0` или запросом
  `POST /api/update/settings {"enabled": false}`. Интервал меняется
  `VIRALCUT_UPDATE_TTL` (секунды).
- Для ручной проверки есть `GET /api/update?force=true`.

### Внутри релиза

- исправления 1.2.2: скачивание в системные «Загрузки», рабочий YouTube,
  точные субтитры, закрытый локальный API и таймауты ffmpeg;
- модель Whisper Small, ffmpeg, 24 шрифта и определитель лиц — в архиве,
  после установки ничего не докачивается.

## Установка

**macOS.** Распакуйте архив и перетащите `ViralCut.app` в «Программы». При первом
запуске может понадобиться правый клик → **«Открыть»**: архив подписан ad-hoc, без
нотаризации Apple.

**Windows.** Распакуйте архив и запустите `ViralCut.exe`. Если SmartScreen
предупреждает: **«Подробнее» → «Выполнить в любом случае»**.

## Известные ограничения

- Проверка обновлений показывает новую версию, но не устанавливает её сама:
  скачивание и замена приложения — следующий шаг.
- YouTube меняет клиентов несколько раз в год; для возрастных, приватных и
  региональных роликов нужны cookies из браузера.
- Windows-сборка собирается в Actions; локально собран только macOS-архив.
